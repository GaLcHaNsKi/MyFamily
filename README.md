# My Family

My Family - это концепт приложения для управлением семьёй. Оно поможет Вам составлять расписание для членов семьи и хранить воспоминания!

## Модули

### The Memory Tree - Ваш архив воспоминаний!

The Memory Tree - это концепт модуля приложения, который позволит Вам хранить Ваши семейные воспоминания и события **В ОДНОМ МЕСТЕ**.
В модуле будет дерево, которое нужно для визуального отображения. В виде ствола выступают родители, в качестве веток - дети.
К каждой из веток можно будет добавлять "листья":
- Фото
- Видео
- Истории в текстовом виде
- И прочее

Причём эти данные будут доступны всем членам семьи и храниться в облаке. Так что о потере или краже телефона, которые повлекут за собой и потерю всех данных, можно бояться меньше.

### Модуль "Рутина"

Этот модуль предназначен для составления планов, обязанностей и задач для членов семьи.
Здесь члены семьи могут:
- Составлять личные планы (чем будет занят и как долго).
- Записывать обязанности каждого, которые нужно выполнять с определённой периодичностью (каждый день, неделю, месяц).

Всё это будет отображаться в общем расписании семьи, чтобы следить за тем, кто занят нужным делом, а кто нет. Это поможет не давать новых задач тем, у кого уже их много, и давать задачи тем, у кого их мало (или вообще нет).

Также в модуле будут отображаться **нужды семьи** (что нужно приобрести, куда сходить, что починить).
